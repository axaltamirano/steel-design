steel-design
============

A Python library implementing AISC 360-22 (*Specification for Structural Steel
Buildings*) with section properties from the 16th Edition *Steel Construction Manual*
and AISC Shapes Database v16.0. All quantities are US customary units, managed
with `pint <https://pint.readthedocs.io>`_.
